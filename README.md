  - Der Fokus liegt auf effizienter Dateiverarbeitung, technischer Analyse und lokaler Ausführung.

## Übersicht

> Das Toolset vereint mehrere eigenständige Anwendungen innerhalb eines gemeinsamen Repositorys. 
  - Der Fokus liegt auf einer kompakten, lokal ausführbaren Werkzeug-Sammlung für PDF-, Bild- und Metadaten-Workflows.

━━━━━━━━━━━━ ◆ ━━━━━━━━━━━━

<br>

## Enthaltene Anwendungen

- **PDF zu JPG Konverter**
- **Image to PDF**
- **Image Metadata Inspector**

> Die Anwendungen bleiben eigenständig nutzbar und werden innerhalb des Toolsets gemeinsam gepflegt und weiterentwickelt.

━━━━━━━━━━━━ ◆ ━━━━━━━━━━━━

<br>

## Technologie

| Bereich | Technologie |
|---|---|
| Sprache | Python |
| Plattform | Desktop |
| Benutzeroberflächen | PySide6 / Tkinter |
| PDF-Verarbeitung | PyMuPDF / ReportLab |
| Bildverarbeitung | Pillow |
| Metadaten | EXIF / IPTC / XMP / ICC |
| Content Provenance | C2PA / Content Credentials |
| Erweiterte Analyse | ExifTool optional |
